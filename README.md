Landing page / front-end shell for Marshall, an AI-powered equity research concept with a market-scanning angle.

## Live Deployment

Production: https://landing-tawny-eight.vercel.app/

## What This Repo Contains

- A lightweight static landing page
- Marshall branding and positioning
- Messaging around market scanning, pattern recognition, and idea generation
- A simple Vercel-deployed front door for the product concept

## Current Messaging Themes

- AI-assisted equity research
- Signal hunting across social, news, and market context
- Pattern recognition for category moves and asymmetric setups
- Fast, clear product positioning in a single-page format

## Stack

- HTML
- CSS
- Vercel

## Local Development

Open the page directly:

```bash
open index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
